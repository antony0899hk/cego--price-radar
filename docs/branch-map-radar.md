# C•E•GO Price Radar｜Branch & Nearby Map Radar

## 目的
由「邊隻貨最平」升級做「今日附近邊間分店最值得去」。

## 核心功能
1. 分店優惠密度
- 不只比較單一商品價格。
- 對每間分店計算：用戶常買清單內有幾多項做緊優惠、總預計節省、今日限定優惠數量。
- 例：
  - 惠康 A 店：5 項常買貨品有優惠，預計慳 $42
  - 百佳 B 店：3 項有優惠，預計慳 $31
  - 萬寧 C 店：牙膏平，但整體購物籃不如 A 店

2. 附近分店地圖
- 取得使用者 GPS（需授權）。
- 顯示附近超市／藥房／零售商分店 pin。
- 每個 pin 顯示：距離、步行時間（如可取得）、今日優惠數量、常買貨品命中數、是否有特別分店優惠。
- 可切換搜尋半徑：500m / 1km / 2km / 5km。

3. 分店評分（不是單純「最平」）
建議分數由：
- 常買貨品命中數
- 預計總節省
- 今日限定／快到期優惠
- 距離／步行時間
- 是否需要會員／優惠券
- 是否屬網店價或分店實體優惠
組合而成。

4. 三種推薦模式
- 最抵：容許去多間店，總價最低。
- 最懶：盡量一間買齊，少行路。
- 最近：附近分店優先，只在價差明顯時建議行遠少少。

5. 分店優惠來源與可信度
- 清楚區分「全線優惠」「網店價」「指定分店優惠」「來源未確認」。
- 若資料來源只到連鎖層級，不可以假裝成某分店一定有。
- 分店級優惠只在有官方／公開分店證據時顯示。

## 與常買／補貨聯動
當某件貨接近補貨期：
1. 先檢查今日價格／promotion。
2. 再檢查附近分店。
3. 如果附近某店同時有多項常買貨品優惠，優先通知「順路一次買齊」。

## 例子
「你屋企附近 1km 有 4 間店：
惠康：鮮奶、廁紙、朱古力 3 樣都平，預計慳 $38
百佳：鮮奶最低，但其他兩樣普通價
萬寧：牙膏有第二件半價
→ 今日最值得去惠康；如果淨係買鮮奶，百佳更平。」

## 地圖 UX
- 地圖上 pin 顏色代表：高優惠密度／普通／只得單一貨品優惠。
- 點 pin 後展開分店卡：地址、距離、今日優惠、常買命中、導航按鈕。
- 同列表模式同步，可按「最抵 / 最近 / 最多優惠」排序。

## 後續資料接入
優先順序：
1. 官方 branch directory / 店舖地址
2. Consumer Council branch/location data（如可合法使用）
3. 零售商官方店舖頁
4. 地圖服務只用作位置／導航補充，不當作價格真相來源

## 原則
Price Radar 的價值不是顯示最多 promotion，而是：
「今日你差不多要買嘅嘢，附近邊間店最值得你去。」
