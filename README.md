# C•E•GO Price Radar V1

核心問題：我要買嘅日用品，今日邊度抵？如果常買貨品或同品牌有 promotion，可以提醒我。

## V1 流程
搜尋貨品 → 比較價格／promotion → 顯示較抵選擇 → 可加入補貨清單。

## 第一階段
- 先做搜尋、價格卡、promotion 標記、補貨提醒概念
- 先驗證 UI 與資料模型
- 真實價格來源逐個接入，不一次過綁死所有零售商

## 後續方向
- 常買貨品清單
- 同款有 promotion 提醒
- 同品牌優惠提醒
- 今日／本週特價提示
- 超市／藥房分類
- 價格歷史與跌價提示

Repo 名目前保留 `cego--price-radar`（雙橫線），避免未確認前擅自改名。
